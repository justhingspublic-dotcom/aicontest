# 視覺定調｜白晝任務簡報(Daylight Mission Briefing)

> 更新:2026-08-06。參考系統:Stripe(`WEB DEMO/DESIGN.md`,由 getdesign.md 下載)。
> 前提約束:0806 規劃之「明亮科技藍+白」基調不可變;所有表單元件自訂樣式,不用瀏覽器內建外觀。

## 個性一句話

**一座白晝裡的任務指揮台**:資訊像儀表讀數一樣精準,介面像金融級產品一樣工整,但骨子裡是軍事航電的語言。

## 從 Stripe 借的(工藝紀律)

- **單一 CTA 色階**:每個區塊只有一顆暖橘實底按鈕(馬上報名);其餘按鈕為藍字白底或描邊。
- **膠囊按鈕**(pill):短促、果斷、交易感;含 hover 抬升與 :active 壓縮回饋。
- **層次陰影 tokens**:`--shadow-sm / --shadow-md / --shadow-focus`,卡片預設 sm、hover md。
- **表單工藝**:聚焦時「邊框變藍+柔和外圈光暈」取代預設 outline;等寬數字(tnum)用於所有金額與日期。
- **淡色底膠囊標籤**(pill-tag-soft):tag 一律淡色底、無邊框。

## 主題自己的(軍事航電語言=簽名元素)

1. **Chakra Petch 展示字體**:方角、儀表感的拉丁字體,只用於讀數與標籤——eyebrow、日期、獎金數字、時間軸節點、品牌章。中文一律 Noto Sans TC,不搶戲。
2. **儀表三色識別帶**(`.camo-strip`):科技藍 55% → 訊號青 27% → 任務琥珀 18% 的硬邊色帶,出現在每頁 header 下緣,像機身識別條。
3. **座標網格背景**:Hero 保留藍色細網格+光暈,白晝版雷達螢幕。

## 字體

- 內文/中文標題:**Noto Sans TC** 400/500/700(Google Fonts,離線退回系統字)。
- 讀數/標籤(僅拉丁與數字):**Chakra Petch** 500/600/700,`font-feature-settings: "tnum"`。

## 自訂元件清單(已不用瀏覽器內建)

- select:`appearance:none` + 內嵌 SVG chevron(聚焦變藍)。
- checkbox:自繪方框,勾選→科技藍實底+白勾(clip-path),含 focus 光暈。
- progress:自訂軌道(天空藍)+藍→青漸層讀數條。
- file input:`::file-selector-button` 改為藍描邊膠囊鈕;上傳清單用自訂 `.file-picker`。
- focus:全表單統一「藍框+`--shadow-focus` 外圈」。

## 禁止

- 大面積黑背景(深藍僅頁尾/CTA 帶/內頁 hero 局部)。
- 同一區塊出現兩顆實底橘按鈕。
- 中文套 Chakra Petch、或給中文標題加誇張字距。
