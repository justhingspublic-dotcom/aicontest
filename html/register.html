報名參賽
REGISTRATION

報名資訊

依照以下流程完成報名。報名與各階段資料上傳期限 待公告； 截止後系統將依階段鎖定指定資料。

PROCESS

報名流程

  1. 建立團隊資料

    填寫團隊名稱、參賽項目與聯絡人資料，不需要另外設定帳號密碼。

  2. 下載並填寫文件

    下載報名表、AI 評測時間預約單、API 規格書與個資同意書，依說明完成填寫。

  3. 上傳並更新資料

    上傳報名表、個資同意書、作品介紹與其他資料；截止日前可更新指定文件。

  4. 查詢階段結果

    送出後可查詢報名狀態與書面／AI 評測結果，入選隊伍再依通知提交決選資料。

DOWNLOADS

報名文件下載

文件名稱與格式已依需求簡報整理；正式檔案尚待主辦單位提供，上架後即可在此下載。

  • DOCX 報名表 -- MB
  • DOCX AI 評測時間預約單 -- MB
  • DOCX API 介面規格說明書 -- MB
  • PDF 個人資料蒐集、處理及利用同意書 -- MB
  • PDF 賽程資訊 -- MB

NOTES

報名注意事項

  • 報名、AI 評測與各階段資料上傳期限 待公告，逾期後系統將依階段鎖定。
  • 報名表與個資同意書送出後不得任意替換；作品介紹、API 規格、AI 評測預約單與補充資料可於截止日前更新。
  • 單檔容量上限 300MB，檔案總數最多 10 個；壓縮資料可使用 7z、zip 或 rar。
  • 上傳檔案請依規範命名與轉檔；缺件或格式錯誤將顯示提醒。
  • 個人資料蒐集、處理及利用同意書需完成簽署後上傳。

PORTAL

進入報名系統

參賽者可直接建立團隊資料並開始報名；正式流程將以聯絡信箱作為通知與後續管理依據，不需設定帳號密碼。

  • 開始報名：建立團隊、選擇項目並填寫聯絡資料
  • 文件管理：下載範本、上傳文件並確認缺件狀態
  • 進度查詢：查看送出狀態、審查階段與最新公告
  • 身分確認：正式系統將以聯絡信箱提供安全管理連結

PASSWORDLESS ENTRY

免帳號密碼報名

直接建立團隊資料並開始上傳報名文件。需要繼續填寫時，再次點選「報名參賽」即可回到目前進度。
